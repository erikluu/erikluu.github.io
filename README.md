# erikluu.github.io

Personal portfolio for Erik Luu, served by GitHub Pages at https://erikluu.github.io.

Plain HTML/CSS/JS with no build step. To preview locally:

```sh
python3 -m http.server 8000   # then open http://localhost:8000
```

- `index.html`, `main.css`: the portfolio page
- `shell-session.js`: the hero terminal animation
- `resume.pdf`: linked from the nav; replace this file to update the resume
- `Pokemon2019/`: a p5.js game from 2019
